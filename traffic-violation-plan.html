Pending

Expected Outcomes

GET /api/reports returns all reports sorted newest-first
Record: id/violationType/lat/lng/timestamp/imageData/exif
IP address explicitly NOT stored
WebSocket broadcast to all clients on each POST

Privacy Guarantees
No login or account required — zero friction for citizens
IP address is explicitly never captured or stored in reports.json
No identity fields (name, email, phone) in the report schema
GPS coordinates are optional — form works if geolocation is denied
Pure data-only submission — EXIF extracted for metadata, not identity
